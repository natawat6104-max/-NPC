- พอผู้ใช้ตัดสินใจแล้ว บันทึกเป็นข้อใหม่ใน `DECISIONS.md` (ข้อถัดไปคือ D16)

## Star Studio (`docs/mockups/star-studio.html`)
- ไฟล์ HTML เดียว ใช้ three.js r128 จาก CDN (cdnjs + jsdelivr: GLTFLoader, FBXLoader, fflate, SkeletonUtils) — ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (`cd docs/mockups && python -m http.server`) ถ้าเปิดเป็นไฟล์ตรง ๆ จะโหลดโมเดลตัวอย่างไม่ได้
- หน้า: ภาพรวม · แผนที่และเส้นทาง · ตัวละคร NPC · รูปลักษณ์ตัวละคร · **ร่างพื้นฐาน 3D** · มอนสเตอร์ · สินค้าและราคา · แม่แบบภารกิจ · วิกฤตประจำบท · แม่แบบพงศาวดาร · พลังกลุ่มดาว · ตัวเลข Balance · ทดสอบจำลอง
- โครงโค้ด: state `S` (บันทึกร่างใน localStorage `star-studio-draft-v1`), `ui`, แต่ละหน้าคือฟังก์ชันใน `SEC_FN`, `render()`/`derived()`, event แบบ delegate ด้วย `data-*`, ตรวจข้อมูลใน `issues()`, จำลองย่อใน `simulate()`
- รูปลักษณ์: `n.look` ต่อ NPC (ผม หมวก เครา สีผิว ชุด ของถือ สีตามอาชีพ สัดส่วน `body`) — ชิ้นหมวก/ผม/ของถือสร้างใน `headParts/torsoParts/handParts`
- ร่างพื้นฐาน: `S.bodies` เก็บแค่ค่าตั้ง (bone map, วัสดุ→สี, ทิศ, ขนาดหมวก) ไฟล์โมเดลเก็บใน IndexedDB; จับคู่กระดูกด้วยชื่อ (`autoMapBones`) ถ้าไม่ได้ใช้รูปร่างโครง (`structuralMap`); ท่าเดิน/ทำงาน/ยืนทำเองใน `animImported` (หมุนกระดูกตามกรอบของตัวละคร) และกำมือตอนถือเครื่องมือ
- โมเดลตัวอย่าง: `SAMPLE_BODY` (v2) โหลด `models/char10-base.glb` อัตโนมัติ (บน claude.ai ใช้ `models/char10-base.glb.b64.txt` เพราะ artifact เสิร์ฟ .glb ไม่ได้)
- มีฉบับเผยแพร่ที่ claude.ai (artifact ส่วนตัวของผู้ใช้) — ไฟล์ใน repo คือต้นฉบับ

## งานที่ค้าง (เรียงตามลำดับ)
1. **ท่าทาง ~100 ไฟล์ใน `C:\Users\Jame\Downloads`** (ผู้ใช้ขอให้ทำบน PC)
   - ดูทุกไฟล์ (.glb/.gltf/.fbx): ชื่อท่า ความยาว มีตัวโมเดลติดมาไหม ใช้กระดูก `Bone_000…` (ตรงกับร่างพื้นฐาน ใช้ได้ทันที) หรือ `mixamorig` (ต้อง retarget ผ่าน bone map)
   - ตัดตัวโมเดลและ texture ออกให้เหลือกระดูก + ท่า (ไฟล์ละไม่ถึง 1 MB) ชื่อกระดูกต้องเหมือนเดิม ห้ามแก้ไฟล์ต้นฉบับใน Downloads
   - เก็บที่ `assets/animations/` ชื่อสั้นภาษาอังกฤษ (`idle.glb`, `walk.glb`, `hammer_strike.glb`) + `index.json` (file, original_file, clip_name, duration_s, loop, skeleton, size_bytes, description_th) + `README.md` ภาษาไทยแยกกลุ่ม: ทั่วไป / งาน (ตีเหล็ก ขุด เก็บเกี่ยว แบกของ รักษา คุย นั่ง) / ยาม / ต่อสู้ / อื่น ๆ
   - รวมเกิน 50 MB ให้ถามผู้ใช้ก่อน; สุ่มเปิดไฟล์ที่ตัดแล้วตรวจความยาวและจำนวนกระดูก
2. **ใส่ท่าจริงใน Star Studio** — อ่าน `assets/animations/index.json`, เพิ่มตัวเลือกท่าในหน้า "ร่างพื้นฐาน 3D"/"รูปลักษณ์ตัวละคร", ผูกท่ากับกิจกรรมของ NPC (เดิน ตีเหล็ก เก็บเกี่ยว รักษา นั่ง ยาม) แทนท่าที่ทำเองใน `animImported`; ท่า Meshy ผูกกับกระดูกตามชื่อได้ตรง ๆ (ระวัง GLTFLoader ลบอักขระพิเศษในชื่อ node)
3. **คู่มือ Godot** — เพิ่มวิธีนำท่าเข้า Godot (AnimationLibrary, Retarget ด้วย BoneMap) ใน `docs/GODOT-IMPORT.md`
4. **ร่างพื้นฐานก่อนทำเกมจริง** — ลดใน Blender (Decimate) จาก 132k เหลือ 8k–15k สามเหลี่ยม; ยังไม่มีเสื้อผ้าและมีวัสดุชิ้นเดียว จึงเปลี่ยนสีชุดตามอาชีพไม่ได้ (ต้องมีชุดเป็นชิ้นหรือแยกวัสดุ) — ถามผู้ใช้ก่อนว่าจะทำชุดอย่างไร
5. **เริ่มโปรเจกต์ Godot** — ยังไม่ได้ตัดสิน (D4): เวอร์ชัน, GDScript หรือ C#, โครงสร้างโฟลเดอร์, เริ่มจากระบบจำลอง (D10) หรือจากภาพ — **คุยกับผู้ใช้ก่อน** ผู้ใช้เคยบอกว่า "เดี๋ยวคุยก่อน"
6. เรื่องที่ยังไม่ตัดสินอื่น ๆ อยู่ท้าย `DECISIONS.md`

## ข้อควรรู้
- ไฟล์ FBX จาก Meshy/Mixamo มักตั้งสีพื้นวัสดุเป็นดำ (texture จะดำ) — Studio แก้ให้เอง ใน Godot ต้องตั้ง albedo เป็นขาว
- ทรงผมสั้นจากชิ้นส่วนยังไม่พอดีหัวของร่างใหม่ ปรับได้ด้วยแถบ "ขนาดหมวก/ผม" / "ยกหมวกขึ้นลง"
