# ท่าทาง (Animations)

ท่าทางทั้งหมด **425 ท่า** ขนาดรวม 34.6 MB — ตัดตัวโมเดลและ texture ออกแล้ว เหลือแค่กระดูก + ท่า (ไฟล์ .glb ไฟล์ละ 1 ท่า)

ข้อมูลทุกท่าอยู่ใน [`index.json`](index.json): `file`, `original_file`, `clip_name`, `group`, `duration_s`, `frames`, `loop`, `root_motion`, `skeleton`, `bones`, `size_bytes`, `description_th`

## สิ่งที่ต้องรู้ก่อนใช้
- **ไม่มีท่าไหนใช้กระดูก `Bone_000…` ของร่างพื้นฐาน** — ทุกท่าต้อง retarget ผ่าน bone map ([`../models/Meshy_AI_Character_output_10.bonemap.json`](../models/Meshy_AI_Character_output_10.bonemap.json))
- ชนิดกระดูก (`skeleton` + `bones`):
  - mixamorig 65 (มีนิ้ว) — 78 ท่า
  - mixamorig 41 (ไม่มีนิ้ว) — 328 ท่า
  - mixamorig 133 (มีนิ้ว + กระดูกผม Hair* ของตัวนินจา ไม่ต้องใช้) — 3 ท่า
  - mixamorig 28 (Meshy v6 ไม่มีนิ้ว) — 14 ท่า
  - Meshy API 24 (Hips, Spine02…) — 2 ท่า
- ชื่อกระดูกเหมือนไฟล์ต้นฉบับ (`mixamorig:Hips` …) — three.js GLTFLoader จะตัด `:` ออกเหลือ `mixamorigHips`
- `loop` = ท่าวนซ้ำได้ (ยืน เดิน วิ่ง ทำงานซ้ำ ๆ) · `false` = เล่นครั้งเดียว (โจมตี หัน ล้ม)
- `root_motion` = สะโพกเคลื่อนที่ไปจริงในท่า (เดินเบี่ยงข้าง ล้ม เลี้ยว) ถ้าจะให้อยู่กับที่ให้ตัดแกนแนวนอนของ Hips — ท่าเดิน/วิ่งตรงส่วนใหญ่อยู่กับที่อยู่แล้ว
- ความเร็ว: Mixamo 30 fps, Meshy 24 fps
- ใช้ใน Star Studio: หน้า "ร่างพื้นฐาน 3D" → การ์ด "ท่าทางของกิจกรรม" (ต้องเปิดเว็บเซิร์ฟเวอร์ที่โฟลเดอร์หลักของ repo)
- นำเข้า Godot: [`docs/GODOT-IMPORT.md`](../../docs/GODOT-IMPORT.md) ข้อ 4 — BoneMap อยู่ใน [`godot/`](godot/) และสคริปต์ตั้งค่าทุกไฟล์ `tools/godot/make_anim_imports.py`
